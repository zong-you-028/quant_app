# 前 150 檔估算市值選股池快照

本資料可用於本次擴大選股池試驗。正確名稱是「**當日有有效收盤報價的上市櫃普通股估算市值前 150**」，估值日為 **2026-10-02**。這是以官方原始欄位計算的固定快照，並非交易所公布的全市場精確市值榜，也不證明擴池後策略績效較好。

## 範圍與日期

上市、上櫃皆必要，任一市場來源失敗、日期不合、缺少有報價普通股的發行股数，或市值單位算術檢查失敗，都拒絕產出名單。普通股使用證交所 ISIN 的 `ES` 類 CFI 加上市／上櫃分類判定；排除 ETF、特別股、TDR，以及估值日後才掛牌的證券。包含 KY 公司與上市創新板普通股。

上市收盤、上市公司基本資料出表日、上櫃每日市值資料皆為 2026-10-02。ISIN 分類頁的實際更新日為 **2026-10-04**；原始回應於 2026-10-03 UTC／2026-10-04 台北時間保存。資料夾名稱沿用本次試驗批次名稱，不代表分類頁的更新日。

這是目前存續公司的固定選股池，**不是歷史逐日成分股資料**。用它回看舊年份仍有存續者偏差與成分選擇前視限制；需另外取得各歷史日期的市值、分類與下市資料，才能宣稱市場範圍也沒有前視。回測中的訊號及成交時間檢查不能消除此限制。

## 估值欄位與單位

| 市場／用途 | 官方欄位 | 本次用法 |
| --- | --- | --- |
| 上市價格 | `STOCK_DAY_ALL.ClosingPrice` | 每股新台幣收盤價 |
| 上市股數 | `t187ap03_L.已發行普通股數或TDR原股發行股數` | 股；先由 CFI 排除 TDR，再用普通股發行股數 |
| 上櫃價格、股數 | `tpex_daily_market_value.ClosePrice`、`Capitals` | 每股新台幣收盤價 × 發行股數 |
| 兩市場排序 | 以上價格 × 普通股股數 | 統一成新台幣估算市值，按未四捨五入乘積排序 |
| 上櫃單位交叉核對 | `MarketValue` | 百萬元尺度與全部 888 檔的股數 × 股價相符，允許官方整百萬元欄位的一百萬元誤差 |
| 上市交叉核對 | 證交所首頁 `ranking.market.AMT` | 億元；只對首頁前 20 中的 19 檔普通股交叉核對，0050 為 ETF，排除 |

上櫃 [OpenAPI schema](https://www.tpex.org.tw/openapi/swagger.json) 只將 `MarketValue` 描述為「市值」，沒有明列單位。因此百萬元單位的證據是所有 eligible rows 的算術一致性，不冒稱已找到官方明文單位說明。正式排序直接使用收盤價 × 股數，不依賴這個未標明單位的欄位。[上市 schema](https://openapi.twse.com.tw/v1/swagger.json) 與 [證交所首頁顯示程式](https://www.twse.com.tw/res/js/web-home.js) 可核對上市欄位及首頁單位；每一個下載資料來源的 URL、下載時間、編碼、原始大小與 SHA256 均在 `sources.json`。

上市採**已發行普通股**，包含私募股份，並非自由流通股或精確上市股數。例如 2408 南亞科，MOPS 普通股 3,450,205,894 股，私募股 351,578,000 股，收盤 526 元；估算發行市值 18,148.083 億元，比證交所首頁上市市值 16,298.78 億元多 11.3463%。私募股 × 收盤價約 1,849.300 億元，與這個差額幾乎一致。因兩種股數定義不同，快照保留完整差異並標記 `estimated`、`provisional`。

沒有採用 `MI_QFIIS.發行股數` 作為排名股數。該資料在本批次的 6669 緯穎仍為 185,840,791 股，較 MOPS 560,199,772 股少；若直接配上同日拆股後 2,085 元收盤價，會嚴重低估市值。原始 `MI_QFIIS` 回應另保存為診斷證據。

## 重建與驗證

在專案根目錄執行：

```powershell
python -m research.universe_150_2026_10_03.build_snapshot
python -m pytest -q test_market_cap_universe.py
```

離線重建會先核對七份官方 gzip 回應解壓後的大小與 SHA256，使用來源記錄的嚴格 UTF-8／CP950 編碼，再重建 `universe_150.json`、`metadata.json`。若與已給歷史下載使用的 `candidate_150.json` 150 檔順序不同，會立即失敗。可用欄位包含 `symbols`、`top150`、`asof`，以及完整 1970 檔排序、邊界、日期、排除與限制。

17 項測試通過，涵蓋跨市場單位與排序、普通股分類、日期不合、來源失敗不能降為單市場、缺報價明示排除、缺股數不能當缺報價隱藏、非有限值、重複代號、發行／上市市值差異檢查、邊界輸出，以及防止最新下載覆蓋封存快照。本次沒有存取正式資料庫或交易帳本。

若要另取最新快照，`core.market_cap_universe` CLI 可使用 `--scope priced_ordinary --allow-issued-listed-difference`；最新 OpenAPI 並非歷史任選日 API，要求的日期必須與實際回應日期一致，不能用最新資料假裝舊日快照。請用新資料夾保存新批次，避免覆蓋本次封存原始檔。

## App 整合與驗證完成

App 已採用此固定 150 池（上市 126、上櫃 24），仍是單一低換手多視窗模型、最多 8 持股、rank 16 續抱緩衝。公開種子已補 103 檔新成分的價量與外資持股；上櫃日常更新走 TPEx 公開來源。啟動更新資料不會每天重新選市值成分。現階段掛牌史採当前市場掛牌日保守過濾，會排除興櫃，也可能排除轉上市前合法上櫃歷史，不能視為完整歷史資格資料。
